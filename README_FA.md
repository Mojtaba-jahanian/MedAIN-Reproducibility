# مخزن MedAIN — راهنمای فارسی

این بسته مخصوص **بارگذاری فایل‌های کد و شواهد عددی در GitHub** آماده شده و شامل تصاویر خام پزشکی، وزن مدل‌های آموزش‌دیده، نامه داوری، PDF پیش‌نویس مقاله یا اطلاعات اتصال سرور نیست.

**نام پیشنهادی مخزن:** `MedAIN-Reproducibility`

**توضیح کوتاه:** `MedAIN retinal segmentation: reproducibility code, archived benchmarks, and audited source-validation analyses.`

برای بررسی عددی مستقل (بدون GPU و بدون دانلود داده):

```powershell
python scripts/verify_results.py
```

**نکته مهم:** نسخه فعلی یک «مخزن کد و شواهد با محدودیت افشاشده» است، نه بسته بازتولید کامل آموزش از صفر. فایل Trainer نهایی Stage9B، داده‌های پردازش‌شده و checkpointها در بسته‌های مبدأ موجود نبودند. تا تکمیل این موارد، در README یا مقاله ادعای «full reproducibility» نکنید.

## روش آپلود

۱. فایل ZIP تحویلی را در ویندوز **Extract All** کنید.

۲. در صفحه `Create a new repository` نام مخزن را `MedAIN-Reproducibility` وارد کنید؛ کادر Description از متن بالا. بهتر است تا بررسی حقوق انتشار و آمادگی علمی، مخزن ابتدا **Private** باشد.

۳. گزینه `Add README` را خاموش بگذارید؛ در بسته README موجود است. `No .gitignore` و `No license` نیز انتخاب کنید تا فایل‌ها و تصمیم حقوقی ما با نسخه آماده تداخل نکند.

۴. پس از ساخت، `Add file` و سپس `Upload files` را انتخاب کنید. **فایل ZIP را به‌عنوان تنها فایل داخل GitHub آپلود نکنید.** محتویات پوشه استخراج‌شده را به GitHub منتقل کنید. چون GitHub وب برای نگه‌داشتن فولدرهای تودرتو محدودیت رابط دارد، راه مطمئن‌تر **Git** است؛ دستورها در `docs/UPLOAD_TO_GITHUB_FA.md` آمده است.

۵. پس از آپلود در Actions اجرای `Verify published aggregate calculations` باید موفق شود. اگر نتیجه متفاوت بود، مخزن را عمومی نکنید و خطا را بررسی کنید.

۶. نام نویسنده در مقاله **Mojtaba Jahanian** و مخزن عمومی باید با همین اطلاعات سازگار باشد. نام `Ha.C.` برای افیلیشن دانشگاه آزاد همدان طبق تأیید نویسنده عیناً در مقاله باقی می‌ماند؛ نیازی به درج افیلیشن کامل در README فنی نیست.
